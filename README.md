# crm-adunik

## Run as a web application

Install dependencies:

```bash
npm install
```

Start the web server:

```bash
npm start
```

Open in the browser:

```text
http://localhost:3000
```

## Notes

- Electron packaging is no longer required for the pure web app version.
- The app still serves the `public/` frontend and backend API from `server.js`.
